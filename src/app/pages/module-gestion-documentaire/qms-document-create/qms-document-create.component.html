Conseils de saisie

Privilégiez le format PDF pour garantir que la mise en page officielle ne soit pas modifiée à la lecture.
Associez les bonnes références officielles (ex: ISO 9001) pour simplifier les prochains audits qualité.
Ciblez le bon processus émetteur afin que le document soit classé au bon endroit dans le QMS.
Définissez une périodicité de révision réaliste (ex: 12 ou 24 mois) pour maintenir sa conformité.
Un niveau de confidentialité restreint le document aux rôles qu'il admet : vérifiez qu'il n'écarte pas ceux qui doivent le valider.
La taille maximale du fichier est de 20 Mo pour assurer un chargement fluide pour tous les collaborateurs.

Ce guide a pour but de vous accompagner dans la création d'un nouveau document Qualité. Veuillez lire attentivement les indications ci-dessous pour assurer la conformité de vos enregistrements.

1. Fichier du document

Les documents internes doivent obligatoirement être importés au format PDF pour assurer le filigranage automatique et la protection. Pour les documents externes, les autres formats (Word, Excel) sont acceptés.

2. Type & processus émetteur

Type : classe le document (Ex: Procédure, Manuel, Instruction). C'est lui, et lui seul, qui détermine le circuit de validation que le document suivra.
Processus émetteur : la structure propriétaire du document, responsable de ses révisions.

3. Périodicité de révision

Indiquez en mois la fréquence à laquelle ce document doit être revu. Le système vous alertera automatiquement à l'approche de la date d'échéance. (Ex: 12 mois pour une revue annuelle).

4. Champs facultatifs

Code du document : votre propre convention de numérotation. Il s'ajoute au numéro attribué à l'enregistrement, il ne s'y substitue pas.
Référence officielle : la norme ou le texte dont le document relève (ex: ISO 9001, AFNOR) — c'est ce que recherche un auditeur.
Domaine d'application et statut légal : le champ d'activité couvert, et ce qui rend le document opposable (obligation réglementaire, recommandation, règle interne).

5. Options de diffusion

Priorité : le degré d'urgence avec lequel le document doit être lu.
Niveau de confidentialité : chaque niveau désigne les rôles admis à consulter le document, et la restriction s'ajoute à celle de la structure. Sans niveau, le document reste visible de toute la structure émettrice. Prenez garde à ne pas écarter les rôles qui doivent le valider : le circuit s'arrêterait faute de décideurs pouvant le voir.
